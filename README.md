# dtefk-system-optimized

Оптимізована система ДТЕФК з покращеним функціоналом, обробкою помилок та новими фічами.

## Запуск у браузері

```bash
python -m http.server 8000
```

Потім відкрийте:

```text
http://localhost:8000/
```

## Збірка в .exe для Windows

Цей проект можна обгорнути в десктопний додаток через Electron і зібрати в один EXE-файл.

1. Встановіть залежності:

```bash
npm install
```

2. Запустіть програму локально:

```bash
npm start
```

3. Зберіть Windows EXE:

```bash
npm run dist
```

Після цього файл появиться у папці `dist/`.

## Примітка

Ця версія не має серверної частини. Вона працює як клієнтський веб-додаток, тому для EXE використовується Electron-обгортка без змін логіки застосунку.
